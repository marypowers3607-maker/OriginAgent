# OriginAgent v2

目标：

20% 高频封装 + 80% 通用执行器。

## 已封装高频能力

- Excel / CSV / TXT / DAT 导入
- 自动列名识别
- 自动 X/Y 选择
- 单曲线 / 多曲线
- line / scatter / column
- Origin 模板入口
- science 风格入口
- 多格式导出
- 保存 OPJU
- 日志
- 控制 Origin 是否保持打开

## 全功能兜底能力

- labtalk: 执行任意 Origin LabTalk
- origin_python: 执行任意 Origin Python

cd C:\OriginAI\agent
